# Personal Portfolio v2

Portfolio satu halaman Willy Fajar Ramadhan: profil, proyek pilihan, dan kontak.

## Language

**Proyek**:
Entri portfolio pilihan yang tampil di section #proyek.
_Avoid_: Project

**Draft**:
Proyek yang tersimpan sebagai file md tapi disembunyikan dari section dan routing.
_Avoid_: Placeholder, hidden

**Urutan**:
Angka eksplisit `order` yang menentukan tampilnya Proyek di section, kecil ke besar.
_Avoid_: Order, no, nomor

**Sampul**:
Gambar utama Proyek yang tampil di section dan halaman detail, disimpan di `src/assets/` dan dioptimasi Astro.
_Avoid_: Plate, cover, image, thumbnail
